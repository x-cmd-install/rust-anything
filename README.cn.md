# rust-anything

[English](./README.md)

用 Rust 逐步重写你的整个应用，每一步都与原应用记录的行为进行核对。支持用 TypeScript、Python、C、Go、Ruby 和 Java 编写的 CLI、HTTP 服务器与库。

[![x-cmd/install — rust-anything Code Quality Monitoring Repo Card](https://x-cmd.com/repo-card/rust-anything.svg)](https://x-cmd.com/install/rust-anything)

## 安装

```sh
x install rust-anything
```
